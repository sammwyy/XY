# 3D Rendering System

XY features a robust 3D pipeline designed for the PS2's unique architecture. It supports meshes, materials, lighting, and camera systems with a forward-looking design that targets VU1 (Vector Unit 1) acceleration.

## Pipeline Architecture

The renderer currently operates in **CPU Mode (EE)** for ease of development and debugging, with the same data structures and flow that the **VU1 Path** will use for hardware acceleration.

```
[Mesh Data] + [Material] + [Model Matrix]
           ↓ (Submit to Queue)
     [XYRenderer3D::flush]
           ↓
   [Matrix MVP = VP * M]
   [Lighting Calculations]
           ↓
    [gsKit Prim Emission]
```

## Core Components

### 1. Meshes (`XYMesh`)
Stores vertex and index buffers. Support for interleaved vertex data (`position`, `normal`, `uv`, `color`).

```cpp
auto cube = xy::primitives::createCube(1.0f);
cube->calcSmoothNormals(); // For curved surfaces
cube->calcFlatNormals();   // For sharp edges
```

### 2. Camera (`XYCamera`)
Manages view and projection matrices. Caches the combined View-Projection matrix for performance.

```cpp
xy::XYCamera camera;
camera.setAspect(640, 448);
camera.lookAt({0, 5, 10}, {0, 0, 0});
```

### 3. Lighting (`XYLightSystem`)
Supports up to 8 active lights. Implements a Blinn-Phong shading model compatible with PS2GL's VU1 microcode.

- **Directional**: Infinite distance, parallel rays.
- **Point**: Omni-directional with constant, linear, and quadratic attenuation.
- **Spot**: Point light with cone-based falloff.

### 4. Materials (`XYMaterial`)
Defines the surface properties: `ambient`, `diffuse`, `specular`, `emission`, and `shininess`.

## Basic Usage

```cpp
#include "graphics/xy_renderer3d.hpp"

// Setup
xy::XYRenderer3D renderer(&graphics());
xy::XYCamera camera;
xy::XYLightSystem lights;

// In draw loop:
renderer.begin(camera, lights);
renderer.drawMesh(*myMesh, modelMatrix, myMaterial);
renderer.flush();
```

## Primitives

The `xy::primitives` namespace provides quick factories for common shapes:
- `createCube(halfExtent)`
- `createSphere(radius, stacks, slices)`
- `createPlane(width, depth, segW, segH)`
- `createCylinder(radius, height, slices)`

## Performance Notes

- **Transformation**: Vertex transformation and lighting are currently computed on the EE (CPU). Keep triangle counts reasonable (~2000-3000 per frame for smooth 60fps) until the VU1 path is implemented.
- **Interleaved Data**: Vertices are stored in a format optimized for the VIF (Vector Interface).
- **Matrix Caching**: `XYCamera` only recomputes matrices when properties change (dirty flag).
- **Normal Matrix**: The renderer automatically computes the inverse-transpose of the model matrix to ensure lighting remains correct even when objects are scaled non-uniformly.

## Raycasting

The camera provides a `screenToWorldRay(ndcX, ndcY)` method which can be used for object selection or basic physics by projecting a ray from the camera into the world.
